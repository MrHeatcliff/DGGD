# PACS representation hypotheses — 2026-09-21

Budget: exactly one Slurm allocation of 4 H200 GPUs, one backbone per worker. No training-campaign restart and no modification of existing ERM results. All four workers must pass an offline GPU smoke test (up to 224 deterministic, class/split-stratified sampled images per domain; pretrained + one final checkpoint) before full analysis starts. Full analysis covers all images, all four held-out domains, and all three final seeds for all four backbones. Feature caches and JSON results make reruns resumable.

1. **Pretraining vs fine-tuning:** refit L2-normalized ridge linear classifiers on pretrained and final features, train only on original source-training split; choose alpha in {0.001,0.01,0.1,1,10,100} by equal-domain source validation. Report full target performance. Ridge is a new diagnostic head, not the original Adam-trained ERM classifier.
2. **Cross-domain class geometry:** balanced same-class cross-domain centroid cosine distance divided by different-class within-domain centroid distance. Up to 40 images per class/domain, using source validation and held-out target only; exactly the same images before/after fine-tuning.
3. **Cross-domain retrieval:** target queries versus all source-validation images, cosine 1-nearest-neighbor class accuracy. Gallery class/domain frequencies follow source-validation frequencies; interpret alongside balanced centroid metrics.
4. **Domain information:** balanced within each class and domain, fixed 50/50 split, fixed-alpha ridge domain probe (chance 25%). Post-hoc diagnostic uses target labels; not model selection. Lower domain accuracy is not sufficient evidence of better class representations.
5. **DINOv2 aggregation:** compare final CLS (768), CLS+mean patch (1536), original four CLS+mean patch (3840), using separately refitted source-only heads on the same features. This isolates readout choice with fixed encoder; it is not end-to-end retraining of each variant.
6. **Representation change:** centered linear CKA between pretrained and finetuned features on the balanced pool. CKA measures change, not correctness or semantic invariance.
7. **Dimension control:** source-train-fitted PCA to 256 dimensions plus identical ridge probe for all backbones. PCA is never fitted on target.

Networks are evaluated with deterministic PACS transforms, BF16 feature extraction and FP32 diagnostic linear algebra. Cached full-run original-head predictions are checked against reported target accuracy. Internet connections are blocked; Unix sockets used by data-loader IPC remain allowed. Seeds and source splits match the recorded ERM pipeline. No target-based checkpoint reselection. No inference that architecture, pretraining data, or learning rate causes the gap without additional controlled retraining. BatchNorm and learning-rate causal interventions are not part of this first analysis.

Output: `outputs/pacs_representation_20260921/{smoke,full}`; full/report.md and full/all_results.json appear after successful completion. Fixed final checkpoints are read from `outputs/pacs_erm_optuna/reports/all_backbones_runs.csv`. Launch scripts run from SLURM_SUBMIT_DIR. Feature caches require roughly 4 GB total; do not commit them.
